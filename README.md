# Portfolio Personal - Anthony Hernández

Portafolio web personal desarrollado con HTML5, CSS3 y JavaScript. Presenta mi perfil como estudiante de Ingeniería de Software, mis habilidades técnicas, mis proyectos destacados.

## Tecnologías

- HTML5 semántico
- CSS3
- JavaScript ES6+
- CSS Custom Properties
- Flexbox
- CSS Grid
- Media Queries
- LocalStorage
- IntersectionObserver
- HTML Dialog API

## Sobre el proyecto 

- Inicio — presentación y llamado a la acción
- Sobre mí — perfil, formación y experiencia
- Skills — tecnologías y herramientas, filtrables por categoría
- Proyectos — proyectos destacados con enlace a repositorio
- Design System — colores, tipografía, espaciado y componentes del sitio
- Contacto — formulario y enlaces directos

## Funcionalidades

- Menú responsive.
- Tema claro/oscuro con localStorage.
- Navegación activa.
- Filtro de habilidades.
- Filtro de proyectos.
- Cards de proyectos generadas con JavaScript.
- Modal de detalles de proyectos.
- Validación del formulario.
- Botón volver arriba.
- Animaciones de entrada.
- Responsive design.
- Accesibilidad básica.
- Design System documentado dentro del sitio.

## Imágenes

Los archivos SVG incluidos en `assets/images/` son imágenes de demostración. Reemplázalos por tu fotografía y capturas reales de tus proyectos manteniendo los nombres de archivo, o modifica las rutas en `index.html` y `js/script.js`.

## Personalización obligatoria

Antes de publicar:

1. Cambia el correo de contacto.
2. Cambia los enlaces de GitHub y LinkedIn.
3. Reemplaza las imágenes de demostración.
4. Revisa las descripciones de proyectos.
5. Coloca los enlaces reales de cada repositorio/demo.
6. Revisa que la información publicada no sea sensible.

## Ejecución

Abre la carpeta en Visual Studio Code y utiliza Live Server para ejecutar `index.html`.

## Nota sobre el formulario

El formulario tiene validación con JavaScript, pero no envía correos todavía. Para recibir mensajes reales debes conectarlo a un backend o servicio de formularios.
