# Portfolio Personal - Anthony Hernández

Portafolio web personal desarrollado con HTML5, CSS3 y JavaScript, cuyo objetivo es presentar mi perfil como estudiante de Ingeniería de Software, mis habilidades técnicas, proyectos académicos y personales, y mi experiencia en el área tecnológica.

El proyecto busca mostrar mi formación, los conocimientos que he adquirido y los proyectos que desarrollo como parte de mi aprendizaje y crecimiento profesional.

## Tecnologías
El proyecto fue desarrollado utilizando las siguientes tecnologías y herramientas:

- HTML5: estructura y organización semántica del contenido.
- CSS3: diseño, estilos, animaciones y adaptación a diferentes dispositivos.
- JavaScript ES6+: interactividad y comportamiento dinámico del sitio.
- CSS Custom Properties: administración de colores, tipografía y variables de diseño.
- Flexbox y CSS Grid: distribución y organización de los elementos.
- Media Queries: adaptación del diseño a diferentes tamaños de pantalla.
- LocalStorage: almacenamiento de preferencias del usuario, como el tema seleccionado.
- IntersectionObserver: detección de elementos visibles para las animaciones de entrada.
- HTML Dialog API: implementación de ventanas modales para mostrar información de los proyectos.

## Sobre el proyecto 
El sitio está organizado en las siguientes secciones:

- Inicio: presentación personal y acceso a las principales secciones.
- Sobre mí: información sobre mi perfil, formación académica y experiencia.
- Habilidades (Skills): tecnologías y herramientas que conozco, organizadas y filtrables por categoría.
- Proyectos: presentación de proyectos académicos y personales con sus respectivas descripciones y enlaces.
- Design System: documentación de los colores, tipografía, espaciado y componentes visuales utilizados en el sitio.
- Contacto: formulario de contacto y enlaces a mis perfiles profesionales.

## Funcionalidades

- Diseño responsive para computadoras, tabletas y dispositivos móviles.
- Menú de navegación adaptable.
- Cambio entre tema claro y oscuro, con preferencia guardada en LocalStorage.
- Indicador de navegación activa.
- Filtro de habilidades por categoría.
- Filtro de proyectos.
- Generación dinámica de tarjetas de proyectos mediante JavaScript.
- Ventanas modales con detalles de los proyectos.
- Validación de campos del formulario de contacto.
- Botón para volver al inicio de la página.
- Animaciones de entrada mediante IntersectionObserver.
- Consideraciones básicas de accesibilidad.
- Sistema de diseño documentado dentro del propio sitio.

## Instalación y visualización
Para ejecutar el proyecto localmente, sigue estos pasos:

## Requisitos previos
- Tener instalado Visual Studio Code.
- Tener instalado un navegador web actualizado, como Google Chrome.
- Contar con la extensión Live Server de Visual Studio Code para ejecutar el sitio mediante un servidor local.

## Pasos para ejecutar el proyecto
Clona este repositorio desde una terminal:

- Ingresa a la carpeta del proyecto
- Abre la carpeta en Visual Studio Code.
- Instala la extensión Live Server si todavía no la tienes.
- Abre el archivo index.html.
- Haz clic derecho y selecciona Open with Live Server.

El portafolio se abrirá automáticamente en tu navegador.
También puedes abrir directamente el archivo index.html en un navegador para visualizar la página, aunque Live Server es recomendable durante el desarrollo.

## Personalización

Para adaptar el proyecto a tu información personal o realizar modificaciones:

- Actualiza la información de perfil, formación y experiencia.
- Configura los enlaces de GitHub y LinkedIn.
- Reemplaza las imágenes de demostración por fotografías y capturas reales.
- Actualiza las descripciones de los proyectos.
- Agrega los enlaces reales a los repositorios y demostraciones.
- Verifica que la información publicada no contenga datos personales sensibles.

## Ejecución

Abre la carpeta en Visual Studio Code y utiliza Live Server para ejecutar `index.html`.

## Nota sobre el formulario

El formulario tiene validación con JavaScript, pero no envía correos todavía. Para recibir mensajes reales debes conectarlo a un backend o servicio de formularios.
